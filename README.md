# RuneDiceMods

A set of [MelonLoader](https://github.com/LavaGang/MelonLoader) mods for the [RuneDice Demo](https://store.steampowered.com/app/3989510/Rune_Dice_Demo/).

## Mods
- Game Speed Selection
	- Adds more game speeds to the selection up to 5x speed.
- Demo Unlocker
	- Unlocks the two other locations that are locked in the demo
- Debug Logging
	- See the game's Debug logs in the melonloader console
